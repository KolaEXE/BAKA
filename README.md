# BAKA

A collection of multiplayer games inspired by anime, manga and Japanese pop culture.

## Games

### Draft
A multiplayer strategy game where players bid, bluff and build teams of anime characters.

**Status:** In development

## Features

- Multiplayer rooms and private matches
- Invite friends using a room code or link
- Spectator mode
- Real-time chat
- Customizable game settings
- AI opponents

## Tech Stack

- HTML, CSS & JavaScript
- GitHub Pages
- Backend services for multiplayer functionality

## About

Baka is an independent project bringing anime-inspired multiplayer games together in one place.

More games and features coming soon.
